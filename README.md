# AIScreenPartner

在 Mac mini 自行開發 APP，取得 AI 工具可用的用量與狀態，呈現在主螢幕旁的小螢幕上。

## 目前決策

- 自行開發 Mac APP、用量資料擷取與畫面繪製，不以現成 AI 用量監控 APP／服務為必要依賴。
- 採購範圍是顯示硬體、固定與供電配件。
- 設計目標：帳號授權與憑證留在 Mac，螢幕只取得顯示內容。
- 尚未採購、實機驗證、安裝 APP 或開始正式實作。

### USB 資料屏的重要區別

已找到圖靈／同類 USB 小螢幕的非官方公開通訊實作，能呈現自訂圖片、文字與進度條。但類似外觀有不同晶片與協定，不能只看 USB-C 接頭就保證相容。

macOS 一般序列傳輸曾有花屏問題；社群有 Mac mini M4 透過直接 USB 傳輸成功的回報。這不是本專案的實機結果。使用者提供的賣場還未確認可對應到該硬體版本，因此目前是樣機候選，並非買來立即可用的產品保證。

## APP 初版目標

- 平台名稱與工作中／完成／錯誤狀態。
- 可取得的當日用量、API 費用、額度與重設時間。
- 少量大字卡片，必要時輪播；顯示資料來源與更新時間。
- 訂閱額度、API 帳單、本地使用估算分開；未知不顯示為零。
- 顯示後端依最終硬體選定，保留 USB 資料輸出與標準延伸顯示器兩種實作可能。
- 各 AI 資料來源後續獨立確認，不承諾所有平台都有完整精確額度。

## 到貨驗收重點

1. 辨認硬體、版本與 USB 裝置身分；先確認協定再送命令。
2. 圖片、漸層、中文、數字與連續多幀測試，不能只因純色能顯示就判定成功。
3. 持續更新 8 小時，檢查花屏、斷線與恢復。
4. 驗證拔插與睡眠喚醒，確認主螢幕與鍵鼠正常。
5. 確認實際重量、線材方向與閱讀距離後設計側掛夾具。

以上均為待執行目標。
