# AIScreenPartner

夾在主螢幕旁的 AI 狀態小螢幕，呈現各 AI 工具的工作狀態、可取得的用量與費用摘要。

## 目前進度

- 2026-11-11（台灣時間）：完成第一輪硬體調查與推薦。
- 尚未採購、尚未實機測試；推薦不代表已驗證相容性。
- 本次只做硬體選型，尚未實作資料收集器與顯示韌體。

## 首選硬體

**Waveshare ESP32-S3-Touch-LCD-4.3B-BOX，原廠 SKU 28141（帶塑膠外殼）。**

選用理由：4.3 吋 / 800×480 適合常駐摘要卡片與簡單趨勢圖，具有 Wi-Fi 與觸控，可自行執行顯示韌體，不必讓手機持續投屏。帶殼版能縮短裝配時間。

| 項目 | 原廠文件列示 |
| --- | --- |
| 螢幕 | 4.3 吋 IPS，800×480，65K 色 |
| 可視角 / 亮度 | 160° / 550 cd/m² |
| 觸控 | 電容式，5 點 |
| 處理器 | ESP32-S3，雙核心，最高 240 MHz |
| 記憶體 | 16 MB Flash、8 MB PSRAM |
| 連線 | 2.4 GHz Wi-Fi；BLE 5 |
| 供電 | USB Type-C 5V；另有 DC 7–36V 輸入口 |
| 功耗參考 | 原廠列示 5V / 450mA，約 2.25W；非本專案實測 |
| 帶殼版正面尺寸 | 116.3 × 79 mm；厚度、重量待確認 |
| 開發 | Arduino / ESP-IDF，支援 LVGL |

這是可程式化 MCU 螢幕，需要開發與燒錄韌體，不能直接用一般瀏覽器開啟任意網頁，也不是 HDMI / USB-C 影音輸入螢幕。本案建議 Wi-Fi 傳資料、USB 供電；「無線」指資料連線，長時間常駐仍安排供電線。第一版不加鋰電池。

## 固定方案

- 建議放在主螢幕左右側，先以橫向 800×480 開發。
- 可設計可拆式 3D 列印側掛支架，配軟墊與螺絲夾；也可評估磁吸轉接座。
- 避免夾具壓迫顯示面板、遮住散熱孔，並讓 USB 線有獨立固定點。
- iCShop 頁面列外殼背面固定孔間距 75 mm，支架另購；孔型、牙規與深度待確認，不能僅依間距就保證通用 VESA 支架適配。
- 夾具開工前需量主螢幕邊框與背殼厚度，確認帶殼螢幕厚度、重量與接口方向。目前不宣稱已找到可直接相容的現成夾具。

## 後續實作方向（尚未實作）

由電腦上的 collector 收集各 AI 的可用資料，經區域網路 HTTP 或 MQTT 傳給 ESP32 顯示端；顯示端用 LVGL 畫卡片、進度條與小型圖表。

- 第一頁：Claude Code / Codex / 其他工具的工作中、完成、失敗狀態。
- 第二頁：可取得的 tokens、API 費用、當日趨勢。
- 第三頁：有資料來源的平台額度與重設時間。
- 正常狀態每 5–15 秒更新，事件狀態可即時推送。
- 每筆資料帶來源、統計範圍、更新時間；沒有資料時顯示「未知」，不顯示為 0。
- 訂閱額度、API 帳單、本地執行紀錄分開呈現。各平台資料取得方式仍需調查，不能承諾每個 AI 都能提供精確剩餘額度。
- AI 服務憑證留在主機端，螢幕端只取得所需摘要資料。

## 到貨驗收目標

以下是待執行的驗收標準，不是測試結果。

1. 使用正確型號官方範例，確認 800×480 顯示、觸控與 USB 燒錄正常。
2. 接上 2.4 GHz Wi-Fi；模擬資料連續更新 8 小時，無異常重啟。
3. 關閉 Wi-Fi 30 秒後恢復，60 秒內自動重連；中斷期間標示離線與最後更新時間。
4. 斷電再上電後自動啟動儀表板。
5. 在實際座位距離約 50–70 cm 可辨識平台名、主數字與警示；不夠清楚就改分頁或放大字體。
6. 夾具能穩定承載，調整主螢幕與輕觸操作時不滑落、不損傷邊框。
